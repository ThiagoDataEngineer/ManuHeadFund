## 🚀 Como Usar

### Setup
```powershell
.\scripts\setup\SETUP_COMPLETO_OCULTO_ADMIN.ps1
```

### Dashboard
```powershell
.\scripts\dashboard\BUILD_DASHBOARD_ELITE.ps1
```

### Manutenção
```powershell
.\scripts\maintenance\PROTECT_NEAR_NOW.ps1
```

### Testes
```powershell
.\scripts\test\TEST_ADAPTIVE_TRAILING.ps1
```

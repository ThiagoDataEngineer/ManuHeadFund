## 1. As 4 Fases de Stan Weinstein

**Referência:** "Secrets for Profiting in Bull and Bear Markets" (1988) — atemporal.

```
FASE 1 — ACUMULAÇÃO (Base)
  Características:
  → Preço lateral após queda prolongada
  → Volume baixo e decrescente
  → Médias móveis achatadas (SMA 30/200 laterais)
  → Pessimismo geral, ninguém fala sobre o ativo
  → Tempo médio: semanas a meses

  O que fazer: começar a acumular lentamente, em silêncio

FASE 2 — MARKUP (Alta)
  Características:
  → Preço rompe a base (Fase 1) com volume crescente
  → SMA 30 começa a subir, preço > SMA 30 consistentemente
  → HH/HL contínuos
  → Narrativa positiva começa a surgir na mídia
  → Tempo médio: meses a anos

  O que fazer: comprar pullbacks para a SMA 30 enquanto Fase 2 ativa

FASE 3 — DISTRIBUIÇÃO (Topo)
  Características:
  → Preço lateral próximo aos topos
  → Volume alto e errático (distribuição para novos entrantes)
  → SMA 30 começa a achatar
  → Euforia, todo mundo fala sobre o ativo
  → Topos e fundos começam a não avançar

  O que fazer: reduzir posições, não comprar mais

FASE 4 — MARKDOWN (Queda)
  Características:
  → Preço quebra o suporte da Fase 3 com volume
  → SMA 30 virou resistência
  → LL/LH contínuos
  → Desespero e negação
  → Tempo médio: meses a anos

  O que fazer: nada ou operar short; aguardar Fase 1 novamente
```

### Regras Weinstein para Entrada
```
COMPRA válida apenas em Fase 2:
  → Preço acima da SMA 30 semanal
  → SMA 30 inclinada para cima
  → Rompimento de resistência com volume

NUNCA comprar em Fase 4 "porque caiu muito"
→ Fase 4 pode durar meses e ir muito mais fundo
```

## 2. Ciclos do Bitcoin — Halving Model

### O Que é o Halving
```
A cada ~4 anos (210.000 blocos), a recompensa por bloco minerado é cortada pela metade.

Histórico:
  2009: 50 BTC por bloco
  2012: 25 BTC (1º halving)
  2016: 12.5 BTC (2º halving)
  2020: 6.25 BTC (3º halving)
  2024: 3.125 BTC (4º halving — Abril 2024)
  2028: 1.5625 BTC (5º halving — previsto)
```

### Padrão Histórico Pós-Halving (Rekt Capital)

```
PRÉ-HALVING (4-6 semanas antes):
  → Correção de 20-40% (sell the news antecipado)
  → Oportunidade de acumulação final

HALVING:
  → Evento em si causa pouca movimentação imediata

PÓS-HALVING (0-6 meses):
  → Período de consolidação / lateralização
  → Mercado "digest" o choque de oferta

BULL MARKET EXPLOSIVO (6-18 meses após halving):
  → 2012 halving → top ~1 ano depois (+8.000%)
  → 2016 halving → top ~17 meses depois (+3.000%)
  → 2020 halving → top ~18 meses depois (+700%)
  → 2024 halving → padrão sugere topo em 2025-2026

BEAR MARKET:
  → Correção de 75-85% do topo
  → Duração: 12-24 meses
  → Fundo geralmente 12-16 meses após o topo
```

### Por que o Padrão se Repete (mas pode divergir)
```
Mecanismo:
  → Choque de oferta: menos BTC novo → supply se reduz
  → Demanda constante ou crescente → preço sobe
  → Narrativa atrai capital novo → aceleração

Fatores que podem mudar o padrão:
  → Adoção institucional (ETFs) aceleram o ciclo
  → Regulação adversa pode interromper
  → Macro global adversa (recessão, crise de crédito) sobrepõe o halving
  → Ciclos tendem a ser menores em amplitude conforme market cap cresce
```

## 3. Macro Cycles — Liquidez Global

**Referência:** Lyn Alden, Michael Howell, Raoul Pal (Real Vision)

### M2 Global e Crypto
```
Correlação forte: M2 global (oferta monetária) e preço do BTC

Quando bancos centrais expandem M2 (QE, cortes de juros):
  → Capital flui para ativos de risco
  → BTC/crypto se beneficia desproporcionalmente

Quando M2 contrai (QT, altas de juros):
  → Capital foge de risco
  → BTC cai mais que ativos tradicionais

Ciclo típico:
  Fed corta juros → M2 cresce → 6-12 meses → BTC rompe → bull market
  Fed sobe juros → M2 contrai → 3-6 meses → BTC começa a cair
```

### DXY (Dollar Index) e Crypto
```
DXY forte (dólar forte) = BTC fraco (geralmente)
DXY fraco (dólar fraco) = BTC forte (geralmente)

Correlação inversa: ~-0.7 no médio prazo
Exceções: quando BTC tem catalisador próprio (halving, ETF approval)
```

### Global Liquidity Cycle (Michael Howell)
```
Howell identifica ciclo de ~5.5 anos de liquidez global

Fase de expansão:
  → Bancos centrais injetam liquidez
  → Credit spreads fecham
  → Risk-on assets sobem: ações, crypto, commodities

Fase de contração:
  → Liquidez reduzida
  → Credit spreads abrem
  → Risk-off: dólar, bonds, ouro

BTC é o "purest play" em liquidez global — amplifica o ciclo
```

## 4. Sazonalidades em Crypto

### Mensal (Bitcoin)
```
Historicamente melhores meses para BTC (média 2010-2024):
  Janeiro:   +30% médio (início de ano otimismo)
  Outubro:   +22% médio ("Uptober" — fase pré-bull)
  Novembro:  +46% médio (bull market aceleração)
  Dezembro:  variável (realização de lucros)

Piores meses historicamente:
  Junho:     -10% médio
  Setembro:  -8% médio ("Rektember")
  Agosto:    -3% médio

⚠️ Sazonalidade é tendência estatística, não certeza.
   Macro e ciclo sobrepõem a sazonalidade.
```

### Semanal
```
Segunda-feira: frequentemente abre com gap (movimento asiático)
Sexta-feira: vencimento de opções na CME (15:00 UTC) — volatilidade
Fim de semana: volume menor, movimentos mais manipuláveis
```

### Intraday
```
00:00-04:00 UTC (Ásia): range consolidado, menor volume
07:00-09:00 UTC (London Open): primeiro movimento direcional
12:00-14:00 UTC (NY Open): maior volatilidade do dia
16:00-17:00 UTC (London Close): reversão frequente
21:00-22:00 UTC (NY Close): fechamento de posições
```

## 5. Altcoin Cycles

### BTC Dominância e Rotação
```
FASE 1 (início do bull):
  → BTC lidera, dominância cresce
  → Altcoins ficam para trás em porcentagem

FASE 2 (meio do bull):
  → ETH começa a superar BTC
  → "ETH season" começa
  → Dominância BTC começa a cair

FASE 3 (late bull / altseason):
  → Dominância BTC < 40%
  → Altcoins de menor cap explodem (+100-1000%)
  → Memecoins e especulação extrema

FASE 4 (fim do bull / início do bear):
  → Dominância BTC sobe rapidamente
  → Altcoins colapsam -90% ou mais
  → "BTC flees to safety" relativo
```

### BTC Dominância como Indicador
```
Dominância subindo + BTC subindo   = bull market early stage (bom para BTC)
Dominância caindo + BTC subindo    = altseason (bom para alts)
Dominância subindo + BTC caindo    = crise sistêmica (tudo cai, BTC menos)
Dominância caindo + BTC lateral    = altcoins liderando curto prazo

Nível atual de dominância define qual estratégia usar:
  > 55%: focar em BTC e grandes caps
  45-55%: mix BTC + ETH
  < 45%: altseason — explorar small caps
```

## 6. Four Year Cycle (Resumo Integrado)

```
ANO 1 (pós-halving): consolidação e início da alta
  → Fase Weinstein 1→2
  → BTC dominância alta
  → On-chain: LTH acumulando, exchange reserve caindo
  → Macro: idealmente M2 crescendo

ANO 2 (bull market): aceleração
  → Fase Weinstein 2 ativa
  → ETH e large caps seguem
  → On-chain: NUPL subindo, funding positivo crescendo
  → Sazonalidade: Outubro-Novembro explosivos

ANO 3 (topo + início do bear): euforia e reversão
  → Fase Weinstein 2→3→4
  → Altseason explosivo (final)
  → On-chain: NUPL > 0.7, MVRV Z-Score > 6, exchange inflow
  → Funding muito positivo, OI máximo

ANO 4 (bear market): capitulação e acumulação
  → Fase Weinstein 4→1
  → On-chain: NUPL < 0, capitulação de mineradores
  → Macro: importante para determinar profundidade e duração
  → Silêncio na mídia = bom sinal (acumulação em silêncio)
```

## Como ler a fase do ciclo no sistema

O agente calcula a fase automaticamente com base em `config.ps1`:

```powershell
$HALVING_DATE              = [DateTime]::new(2024, 4, 19)
$CYCLE_CONSOLIDATION_MONTHS = 6   # até aqui: CONSOLIDACAO-POS-HALVING
$CYCLE_BULL_MONTHS          = 18  # até aqui: BULL-HISTORICO
$CYCLE_DISTRIBUTION_MONTHS  = 24  # até aqui: POSSIVEL-DISTRIBUICAO
                                   # além: POSSIVEL-BEAR
```

Para saber a fase atual, calcule:
```
meses pós-halving = (hoje - 2024-04-19) / 30.4 dias

Exemplos:
  Mai/2024 (1m)  → CONSOLIDACAO-POS-HALVING
  Out/2024 (6m)  → BULL-HISTORICO (começo)
  Mai/2026 (25m) → POSSIVEL-DISTRIBUICAO  ← fase atual
  Mai/2027 (37m) → POSSIVEL-BEAR
```

> Este cálculo é automático no FundAgent — o campo `fase_ciclo` no JSON de saída
> reflete a fase calculada dinamicamente, não valores fixos desta documentação.

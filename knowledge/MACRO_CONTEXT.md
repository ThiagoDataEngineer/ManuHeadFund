## Por que Macro Importa para Crypto

> "Bitcoin is a macro asset. You cannot analyze it in isolation."
> — Raoul Pal, Real Vision

- BTC correlaciona fortemente com liquidez global (M2)
- Em crises de liquidez, crypto cai mais que qualquer outro ativo
- Decisões do FED movem crypto tanto quanto halvings
- Compreender macro = saber QUANDO entrar no ciclo, não só como

## 1. Federal Reserve (FED) — EUA

### Ferramentas e Impacto em Crypto

```
TAXA DE JUROS (Fed Funds Rate):
  Alta → dinheiro mais caro → capital foge de risco → bearish crypto
  Baixa → dinheiro mais barato → capital busca risco → bullish crypto
  
  Timing: mudanças levam 6-12 meses para impactar mercados de risco

QE (Quantitative Easing):
  → FED compra bonds, injeta dólares no sistema
  → Aumenta liquidez → bullish para todos os ativos
  → 2020-2021: QE massivo = maior bull market da história do BTC

QT (Quantitative Tightening):
  → FED vende bonds, retira dólares do sistema
  → Reduz liquidez → bearish para ativos de risco
  → 2022: QT + alta de juros = maior bear market desde 2018

FOMC (reuniões do FED):
  → 8 reuniões por ano
  → Dias antes e depois = alta volatilidade
  → "Buy the rumor, sell the news" frequente
```

### Indicadores FED para Monitorar
```
Fed Funds Futures → o que o mercado espera que o FED faça
  → Se mercado espera corte → bullish antecipado

Dot Plot → projeções dos membros do FED para taxas futuras
  → Dot plot dovish (taxas caindo) = combustível para rally

Balance Sheet Size → tamanho do balanço do FED
  → Crescendo = injeção de liquidez = bullish
  → Encolhendo = retirada de liquidez = bearish
```

## 2. DXY (US Dollar Index)

```
O que é:
  → Índice do dólar contra cesta de moedas (EUR, JPY, GBP, CAD, SEK, CHF)
  → DXY forte = dólar forte

Correlação com BTC:
  Correlação histórica: -0.65 a -0.75 no médio prazo
  
  DXY subindo → BTC geralmente cai (liquidez em dólar reduz apetite por risco)
  DXY caindo  → BTC geralmente sobe (fuga do dólar → ativos alternativos)

Zonas técnicas relevantes do DXY:
  → DXY > 105: ambiente desafiador para crypto
  → DXY < 100: ambiente favorável para crypto
  → Suporte/resistência no DXY = pontos de inflexão para crypto

Exceções:
  → Quando crypto tem catalisador próprio (halving, ETF), correlação quebra
  → Em crises de liquidez aguda, tudo cai junto (correlação vai a 1)
```

## 3. M2 Money Supply (Liquidez Global)

```
O que é:
  → Medida da oferta de dinheiro em circulação
  → M1 (cash + depósitos) + contas poupança e equivalentes

Correlação BTC-M2:
  → Correlação de 90%+ observada por Lyn Alden em janela de 12 meses
  → M2 global (EUA + China + Europa + Japão) = mais preditivo
  → BTC acompanha M2 com lag de 6-12 meses

Fontes:
  → Fred.stlouisfed.org (M2 EUA)
  → Yardeni Research (M2 global)
  → WorldMoneySupply (Twitter/X: Global M2)

Interpretação prática:
  M2 crescendo acima de 5% a.a. → ambiente favorável (2020-2021: +25% a.a.)
  M2 contraindo → ambiente desfavorável (2022: M2 caiu pela primeira vez em décadas)
```

## 4. Macro Ciclo de Dívida (Ray Dalio)

```
Dalio descreve dois ciclos de dívida:

Curto Prazo (5-10 anos):
  → Expansão de crédito → boom econômico
  → Excesso de dívida → crise → desalavancagem
  → BTC pode ser usado como hedge

Longo Prazo (50-75 anos) — "Big Debt Cycle":
  → Acúmulo de dívida soberana ao longo de décadas
  → Eventual monetização da dívida (imprimir dinheiro)
  → Desvalorização de moedas fiat
  → BTC como reserva de valor se beneficia muito nesse cenário

Status atual (2024-2026):
  → EUA com dívida/PIB > 120%
  → FED preso: subir juros demais quebra o sistema de dívida
  → A longo prazo, mais QE parece inevitável = bullish BTC estrutural
```

## 5. Correlação com S&P 500

```
Correlação histórica BTC-SP500:
  2017-2019: baixa correlação (BTC independente)
  2020-2021: correlação cresceu (institucionalização)
  2022: correlação ~0.75 (caíram juntos com QT do FED)
  2023-2024: correlação moderada

Quando correlação é alta:
  → Analizar SP500 como proxy de apetite por risco global
  → SP500 despencando = crypto também → reduzir risco

Quando correlação quebra:
  → Evento específico de crypto (halving, ETF, hack)
  → BTC pode subir mesmo com SP500 lateral/caindo (fase de acumulação discreta)
```

## 6. Yield Curve

```
O que é:
  → Diferença entre juros de longo prazo (10 anos) e curto prazo (2 anos)

Yield Curve Invertida (10y < 2y):
  → Historicamente precede recessão em 12-18 meses
  → 2022-2023: curva mais invertida em 40 anos

Impacto em crypto:
  → Curva invertida = stress no sistema bancário = risk-off
  → "Uninversion" (curva voltando ao normal) geralmente ocorre DURANTE recessão
  → Após uninversion: janela de compra histórica em ativos de risco
```

## 7. China e Macro Asiático

```
PBOC (Banco Central da China):
  → Injeções de liquidez do PBOC = bullish para BTC (especialmente altcoins)
  → Restrições regulatórias da China criam volatilidade (já ocorreu múltiplas vezes)

Yuan (CNY):
  → Desvalorização do Yuan → fuga de capital para BTC (especialmente 2015-2016)
  → Controles de capital chineses aumentaram demanda por crypto como saída de capital

Yen Carry Trade (Japão):
  → Investidores pegam emprestado em yen (juros zero) e investem em risco
  → Quando BOJ sobe juros → liquidação do carry trade → venda de ativos de risco
  → Agosto 2024: carry trade japonês foi desfeito = queda de 20% em 3 dias
```

## 8. ETFs e Fluxos Institucionais

```
Bitcoin Spot ETFs (aprovados EUA - Jan 2024):
  → BlackRock IBIT, Fidelity FBTC, ARK 21Shares, etc.
  → Fluxos diários movem o mercado

Monitorar:
  → Bitconstampede.com ou SoSoValue: fluxos ETF diários
  → Dias de inflow forte → suporte para preço
  → Dias de outflow grande → pressão vendedora institucional

Ethereum ETF (aprovado EUA - Jul 2024):
  → Similar ao BTC mas com fluxos menores

Impacto estrutural dos ETFs:
  → Reduz volatilidade no longo prazo (novo supply absorvido)
  → Cria demanda contínua e previsível
  → Acelera ciclos (compressão do padrão histórico de 4 anos?)
```

## 9. Framework de Leitura Macro Semanal

```
Checklist toda segunda-feira:
  □ Taxa do FED mudou? Próxima reunião quando?
  □ DXY em tendência de alta ou baixa? Suporte/resistência?
  □ M2 global crescendo ou contraindo? (mensal)
  □ SP500 acima ou abaixo da SMA 200?
  □ VIX (volatilidade SP500) acima de 20? (risk-off se sim)
  □ ETF BTC: inflow ou outflow na semana?
  □ Notícias regulatórias pendentes?
  □ Dados macro importantes esta semana? (CPI, NFP, FOMC)

Calendário econômico: investing.com/economic-calendar
```

## 10. Macro Favorável vs Desfavorável (Resumo)

```
MACRO FAVORÁVEL para crypto:
  ✓ FED cortando juros ou sinalizando corte
  ✓ DXY caindo ou lateral abaixo de 100
  ✓ M2 global crescendo
  ✓ SP500 em tendência de alta
  ✓ ETF inflows positivos
  ✓ China injetando liquidez
  ✓ Yield curve desinvertendo

MACRO DESFAVORÁVEL para crypto:
  ✗ FED subindo juros ou hawkish
  ✗ DXY subindo acima de 105
  ✗ M2 global contraindo
  ✗ SP500 abaixo da SMA 200
  ✗ ETF outflows grandes
  ✗ Crise de crédito (spreads de crédito abrindo)
  ✗ Regulação adversa iminente em grandes mercados
```

## O Que Define o 1% Prático

Não é o trader que acerta mais. É o trader que:

```
1. Aplica o sistema com consistência — mesmo nas sequências ruins
2. Sobrevive aos erros de iniciante sem destruir a conta
3. Aprende com dados próprios (journal), não com intuição
4. Adapta a estratégia quando o mercado muda — sem abandonar os princípios
5. Tem track record real auditável ao longo de ciclos completos (bull + bear)
```

O 1% teórico sabe tudo isso. O 1% prático **faz** tudo isso.

## Fase 0 — Antes de Arriscar Capital Real (2-4 semanas)

### Objetivos
```
→ Verificar se você consegue EXECUTAR o sistema sem emoção
→ Identificar quais regras você naturalmente quebra (isso é informação valiosa)
→ Calibrar expectativas realistas de win rate e drawdown
```

### O que fazer
```
1. Paper trading ou conta demo por no mínimo 30 trades
   → Usar os mesmos setups, stops e tamanhos que usaria com dinheiro real
   → A maioria das pessoas não faz isso — e paga caro por pular esta etapa

2. Criar o journal ANTES de abrir qualquer trade
   Registrar obrigatoriamente:
   □ Setup: qual padrão? (flag, pullback, OB, etc.)
   □ Timeframe de entrada e HTF confirmando
   □ Entrada exata + razão
   □ Stop loss + razão (estrutural, ATR, etc.)
   □ Alvo + razão
   □ R:R calculado
   □ Tamanho da posição calculado (1% rule)
   □ Resultado
   □ O que aconteceu (o mercado fez o que eu esperava?)
   □ Erro cometido (se houve)

3. Ao final das 30 operações: calcular
   → Win rate
   → R:R médio realizado
   → Expectância
   → Qual setup teve melhor resultado?
   → Qual erro se repetiu mais?
```

### O que você vai descobrir
```
Quase todo trader descobre que:
  → Move stops mentalmente antes de eles serem atingidos
  → Sai antes do alvo por medo de perder o lucro
  → Entra em setups que não preenchem todos os critérios "porque parece bom"
  → Opera mais quando acaba de perder (revenge) ou ganhar (overconfidence)

Descobrir isso em demo custa zero. Descobrir com dinheiro real custa muito.
```

## Fase 1 — Conta Pequena Real (1-3 meses)

### Por que não demo para sempre?
```
Sem consequência real → sem emoção real → não prepara para o que importa.

Tamanho sugerido para essa fase:
  → Capital que, se perder 50%, você sentirá mas NÃO mudará sua vida
  → Ex: R$500 a R$2.000 para a maioria das pessoas
  → O objetivo não é lucrar — é aprender a executar sob pressão emocional real
```

### O que muda com dinheiro real
```
Fenômenos que só surgem com capital real:
  → "Paralisia de análise" — você sabe o setup mas não consegue apertar o botão
  → "Saída prematura" — você sai com +$3 de $50 alvo porque tem medo de perder
  → "Stop mental" — você decide mentalmente não usar stop "dessa vez"
  → "Tamanho dobrado" — você aumenta posição para "recuperar" a perda anterior
```

### Métricas para avançar desta fase
```
Para passar para a próxima fase, exigir todos:
  □ 50+ trades registrados no journal
  □ Expectância positiva (EV > 0)
  □ Nenhuma violação das regras de risco (1% máximo) nas últimas 20 trades
  □ Você consegue identificar seu edge: "meu melhor setup é X no timeframe Y"
  □ Drawdown máximo no período < 15% da conta
```

## Fase 1.5 — Protocolo de Recuperação Pós-Prejuízo

> A KB cobre o ERRO ("dobrar tamanho para recuperar" em Fase 1) e o GUARD-RAIL
> ("Regra dos 3 stops" em RISK_MANAGEMENT.md). Faltava o PROTOCOLO de retomada —
> o que fazer DEPOIS que o circuit breaker disparou e o capital encolheu.

### Por que existe

Trader técnico sabe que revenge trade destrói conta. O que destrói **carreira** é o
modo "vida louca" (Stormer) pós-drawdown sério: voltar a operar igual antes,
buscando recuperar o capital perdido no mesmo tempo que demorou pra perder.
O capital pode até retornar; a disciplina não retorna sozinha.

### Os 3 níveis de drawdown e o protocolo correspondente

```
NÍVEL VERDE (-5% conta):
  → Operação normal continua
  → Journal: marcar "ciclo verde" para auditoria semanal
  → Nenhuma mudança de tamanho

NÍVEL AMARELO (-15% conta):
  → Reduzir tamanho de posição à METADE por 10 trades consecutivos
  → Re-validar 3 setups principais em paper antes de voltar ao tamanho cheio
  → Pausa obrigatória de 48h se drawdown ocorreu em <5 dias
  → Critério de retorno: 10 trades dentro das regras (não 10 trades vencedores)

NÍVEL VERMELHO (-25% conta):
  → STOP TOTAL por 7 dias corridos. Sem exceção.
  → Auditoria forçada: imprimir últimas 30 trades, marcar quais violaram regra
  → Voltar com 1/4 do tamanho anterior por 20 trades
  → Re-leitura obrigatória de RISK_MANAGEMENT.md + MENTOR.md
  → Se segundo nível vermelho em 90 dias: pausa de 30 dias + revisão de edge
```

### O que NÃO fazer (anti-padrões clássicos)

```
× Aumentar tamanho para "recuperar mais rápido"  → revenge trade
× Trocar de estratégia mid-drawdown                → vira shotgun de viés
× Operar timeframe menor para "pegar mais sinais"  → noise overrides edge
× Pular jornal porque "tá sofrendo"                → perde dados da única vez que importam
× Buscar nova fonte/livro/curso                    → procrastinação disfarçada
```

### Métricas para sair do protocolo

```
Para sair do AMARELO:
  □ 10 trades consecutivos dentro das regras (1% risk, stop antes)
  □ Expectância >0 no batch de 10
  □ Zero stop mental violado

Para sair do VERMELHO:
  □ Atender critérios do AMARELO
  □ + 20 trades adicionais sem nenhuma violação
  □ + drawdown do batch < 5%
  □ + auditoria escrita identificando causa raíz do -25%
```

> *"O trader que não tem um plano para o pior dia já planejou perder a conta."*
> — adaptado de Stormer

## Fase 2 — Especialização no Nicho (3-6 meses)

### O Erro do Iniciante Sofisticado
```
Quem leu muito sobre trading conhece 20 setups diferentes.
O problema: tentar operar todos os 20 cria inconsistência.

O 1% prático escolhe 2-3 setups e os domina completamente:
  → Conhece cada variação do setup
  → Sabe exatamente quais contextos o setup funciona e quais não
  → Tem dados de 100+ ocorrências para confiar no edge
  → Executa sem hesitação quando o setup aparece
```

### Como escolher seu nicho
```
Responda honestamente:
  1. Qual timeframe se encaixa na sua vida? (scalp = tela o dia todo)
  2. Qual mercado você mais entende? (BTC, altcoins, perps, spot)
  3. Qual tipo de setup você executou melhor no journal?
  4. Você prefere alta frequência de trades (scalp) ou paciência (swing)?

Exemplos de especialização:
  → "Só opero pullback para EMA 21 no BTC 1h com bias do daily"
  → "Só opero ORB nos primeiros 30min da sessão NY em BTC perp"
  → "Só opero liquidity sweeps no 15m quando funding rate é extremo"
```

### Como aprofundar a especialização
```
1. Coletar 100 ocorrências históricas do seu setup no TradingView
   → Marcar cada uma com o resultado
   → Identificar o contexto que aumenta o win rate

2. Criar regras de filtro baseadas em dados, não em opinião
   Ex: "esse setup tem 65% de win rate geral, mas 78% quando ADX > 25"
   → ADX > 25 vira filtro obrigatório

3. Documentar o "setup ideal" com todos os critérios
   → Imprimir e colocar ao lado do monitor se necessário
   → Nunca entrar em trade que não preencha todos os critérios
```

## Fase 3 — Consistência Comprovada (6-18 meses)

### O que significa ser consistente
```
Não é: "ganhei dinheiro este mês"
É: "meu sistema gerou resultados dentro do esperado por 6+ meses"

Expectativas realistas de um trader consistente:
  → Win rate dentro de ±5% da média histórica do sistema
  → Drawdown máximo dentro do esperado pelo backtest
  → Nenhum mês com violação das regras de risco
  → Lucro líquido após custos (taxas, spreads) positivo no período
```

### Journal de alto nível
```
Além dos campos básicos da Fase 0, adicionar:
  □ Estado emocional antes do trade (1-10: 1=ansioso, 10=neutro)
  □ Qualidade do setup (A, B, C — só entrar em A e B)
  □ Se o mercado estava em tendência, range ou transição
  □ Revisão semanal: qual padrão de erro se repete?
  □ Revisão mensal: expectância está melhorando ou piorando?

O journal é o único dado honesto que você tem.
Tudo mais é ruído.
```

### Adaptação sem abandono de princípios
```
Mercados mudam. Estratégias que funcionaram em 2021 podem não funcionar em 2025.

Como detectar que seu edge mudou:
  → Win rate caiu > 10% em relação à média histórica por 3+ meses
  → Drawdown ultrapassou 2x o máximo histórico do backtest
  → O contexto de mercado mudou estruturalmente (ex: ETFs chegaram e mudaram liquidez)

O que fazer:
  → Voltar para paper trading com o setup modificado
  → Testar a hipótese antes de mudar a conta real
  → Nunca mudar a estratégia no meio de uma sequência de perdas (viés emocional)
```

## Fase 4 — O Que os 1% Fazem Que os Outros Não Fazem

### Eles operam menos, não mais
```
Amadores: buscam trades o tempo todo (FOMO de oportunidade)
Top 1%: esperam o setup perfeito, mesmo que seja 1 trade por dia ou por semana

"I just wait until there is money lying in the corner, and all I have to do
 is go over there and pick it up. I do nothing in the meantime."
— Jim Rogers
```

### Eles protegem capital antes de pensar em lucro
```
Regra de Druckenmiller:
  "The first priority is to not lose. The second is to not lose.
   The third is to make money."

Na prática:
  → Reduzir tamanho quando o mercado está confuso
  → Aumentar tamanho quando o setup é excepcional (raro)
  → A assimetria de tamanho é onde a maioria do alpha vem
```

### Eles têm um processo, não uma previsão
```
Amadores: "acho que BTC vai subir para $120k"
Top 1%: "se BTC romper $X com volume e funding neutro,
         entro com stop em $Y e alvo em $Z, R:R de 1:3"

A diferença:
  → Amadores precisam estar certos sobre o futuro para ganhar
  → Profissionais têm um plano para qualquer cenário
```

### Eles sabem quando o mercado não favorece seu estilo
```
Scalper em mercado de baixo volume = perda certa
Swing trader em mercado altamente volátil sem tendência = perda certa

O 1% identifica: "meu setup não está aparecendo este mês" → não opera
O restante opera de qualquer forma porque "precisa" ganhar
```

### Eles medem tudo e não confiam na memória
```
A memória humana sobre trading é sistematicamente otimista:
  → Você lembra dos winners com mais clareza que os losers
  → Você lembra das vezes que "seu instinto estava certo"
  → Você esquece quantas vezes o instinto estava errado

Journal elimina esse viés.
Dados do journal > memória, sempre.
```

# WYCKOFF METHOD + SMART MONEY CONCEPTS

> Wyckoff: Richard Wyckoff (1930s), atualizado por Robert Evans e Todd Krueger.
> SMC/ICT: Michael Huddleston (Inner Circle Trader), popularizado a partir de 2018.
> Ambas as metodologias explicam o mesmo fenômeno: como instituições operam.

---

## PARTE 1 — WYCKOFF METHOD

### Três Leis Fundamentais

**1. Lei da Oferta e Demanda**
```
Demanda > Oferta → preço sobe
Oferta > Demanda → preço cai
Equilíbrio       → lateral (range)
```

**2. Lei de Causa e Efeito**
```
Acumulação (causa) → Bull market (efeito)
Distribuição (causa) → Bear market (efeito)
Quanto maior a causa (range), maior o efeito (movimento)
```

**3. Lei do Esforço vs Resultado**
```
Volume alto + movimento grande   → esforço = resultado (harmonia)
Volume alto + movimento pequeno  → absorção (reversão potencial)
Volume baixo + movimento grande  → sem oposição (tendência forte)
```

---

### As 4 Fases de Wyckoff

```
FASE 1: ACUMULAÇÃO
  ↓ (downtrend anterior)
  ├── Preliminary Support (PS)    → primeiro suporte após queda
  ├── Selling Climax (SC)         → pânico final, volume explode
  ├── Automatic Rally (AR)        → bounce técnico
  ├── Secondary Test (ST)         → retesta o SC com volume menor
  ├── [Trading Range]
  ├── Spring / Shakeout           → fakeout abaixo do range (stop hunt)
  └── Sign of Strength (SOS)      → rompimento com volume = confirmação

FASE 2: MARKUP (alta)
  └── Bull market em desenvolvimento

FASE 3: DISTRIBUIÇÃO
  ├── Preliminary Supply (PSY)    → primeiro topo após alta
  ├── Buying Climax (BC)          → euforia final, volume explode
  ├── Automatic Reaction (AR)     → queda técnica
  ├── Secondary Test (ST)         → retesta o BC com volume menor
  ├── [Trading Range]
  ├── Upthrust After Distribution → fakeout acima do range
  └── Sign of Weakness (SOW)      → quebra com volume = confirmação

FASE 4: MARKDOWN (queda)
  └── Bear market em desenvolvimento
```

### Spring — O Setup Mais Poderoso do Wyckoff
```
Condição:
  1. Mercado em range de acumulação (mínimos e máximos definidos)
  2. Preço quebra o suporte do range (stop hunt de compradores)
  3. Volume no break é MENOR que o SC anterior (ou não explosivo)
  4. Preço volta rapidamente para dentro do range (rejeição)
  5. Volume cresce na recuperação

Entrada:
  - Comprar no reteste do breakout (que falhou)
  - Stop abaixo do Spring
  - Alvo: VAH (topo do range) e além
```

### Upthrust — Espelho do Spring (em distribuição)
```
Condição:
  1. Mercado em range de distribuição
  2. Preço quebra a resistência do range (stop hunt de vendedores)
  3. Rejeição rápida de volta para dentro do range
  4. Volume não confirma o breakout

Entrada:
  - Vender no reteste do false breakout
  - Stop acima do Upthrust
  - Alvo: VAL (fundo do range) e abaixo
```

## PARTE 2 — SMART MONEY CONCEPTS (SMC / ICT)

> SMC é uma evolução moderna do Wyckoff, com nomenclatura própria.
> Foco: entender onde bancos, fundos e market makers colocam ordens.

### Estrutura de Mercado (Market Structure)

```
Break of Structure (BOS):
  → Confirmação de continuação da tendência
  → Alta: quebra do topo anterior com fechamento acima
  → Baixa: quebra do fundo anterior com fechamento abaixo

Change of Character (CHoCH):
  → Primeiro sinal de reversão da tendência
  → Alta que vira baixa: primeiro HH → agora quebra o último HL
  → Baixa que vira alta: primeiro LL → agora quebra o último LH
```

### Order Blocks (OB)

> Zonas onde bancos executaram ordens grandes. Preço frequentemente retorna para testar.

```
Bullish Order Block:
  - Último candle VERMELHO antes de um movimento forte de ALTA
  - Zona: do open ao close desse candle vermelho
  - Quando preço retorna a essa zona → alta probabilidade de bounce

Bearish Order Block:
  - Último candle VERDE antes de um movimento forte de BAIXA
  - Zona: do open ao close desse candle verde
  - Quando preço retorna a essa zona → alta probabilidade de queda

Validação:
  → OB deve ter causado um BOS no lado contrário
  → Quanto mais distante o preço foi após o OB, mais forte a zona
```

### Fair Value Gap (FVG) / Imbalance

```
FVG Bullish (gap de alta):
  - Candle 1: máxima X
  - Candle 2: gap de alta (muito forte)
  - Candle 3: mínima Y > X
  → Gap entre X e Y = zona de imbalance
  → Preço tende a "preencher" o gap antes de continuar

FVG Bearish (gap de baixa):
  - Candle 1: mínima X
  - Candle 2: gap de baixa (muito forte)
  - Candle 3: máxima Y < X
  → Gap entre X e Y = zona de imbalance para baixo
```

### Liquidity — O Conceito Central do ICT

> O mercado é movido pela busca de liquidez (stops e ordens pendentes).
> Bancos precisam de liquidez para executar posições grandes.

```
Buy-Side Liquidity (BSL):
  - Stops de vendedores + ordens de compra = acima de topos/resistências
  - Preço sobe para "varrer" esses stops antes de reverter para baixo
  - Identificar: Equal Highs, resistências óbvias, topos de range

Sell-Side Liquidity (SSL):
  - Stops de compradores + ordens de venda = abaixo de fundos/suportes
  - Preço cai para "varrer" esses stops antes de reverter para cima
  - Identificar: Equal Lows, suportes óbvios, fundos de range

Liquidity Sweep:
  → Quando o preço ultrapassa uma zona de liquidez e reverte
  → Sinal de que o Smart Money executou suas ordens
  → Entrada no reversal após o sweep
```

### Killzones — Horários de Liquidez Institucional

```
Asian Session KZ:   00:00 – 04:00 UTC  (define range do dia)
London Open KZ:     07:00 – 09:00 UTC  (maior volume europeu)
NY Open KZ:         12:00 – 14:00 UTC  (maior volatilidade do dia)
London Close:       16:00 – 17:00 UTC  (reversão frequente)
NY Lunch:           17:00 – 19:00 UTC  (baixo volume, evitar)
NY Close:           21:00 – 22:00 UTC  (posições fechadas)
```

### ICT Concepts Avançados

**Optimal Trade Entry (OTE)**
```
Após um impulso, aguardar retracement de 61.8% a 78.6%
Combinar com OB ou FVG nessa zona = entrada de alta probabilidade
```

**Displacement**
```
Movimento forte e rápido que cria FVG
Indica que Smart Money acabou de entrar
Aguardar retorno ao FVG para entrar na mesma direção
```

**Institutional Candle**
```
Candle com corpo muito grande que engole múltiplos candles
Indica posicionamento institucional
Zona do candle = OB para futuros retraces
```

**Power of 3 (PO3)**
```
Estrutura intraday de 3 fases:
  1. Accumulation: Asian session consolida (define range)
  2. Manipulation: London/NY break falso do range (stop hunt)
  3. Distribution: movimento real na direção oposta ao fakeout

Exemplo clássico:
  Asian range: 100-102
  London: quebra para 99.5 (stop hunt dos compradores)
  NY: impulso para 105+ (movimento real de alta)
```

## Comparativo Wyckoff vs SMC

| Conceito Wyckoff | Equivalente SMC |
|-----------------|-----------------|
| Spring | Sell-Side Liquidity Sweep |
| Upthrust | Buy-Side Liquidity Sweep |
| Selling Climax | High Volume Displacement (Bearish) |
| Buying Climax | High Volume Displacement (Bullish) |
| Sign of Strength | Break of Structure (Bullish) |
| Sign of Weakness | Break of Structure (Bearish) |
| Composite Operator | Smart Money / Institutions |
| Trading Range | Accumulation/Distribution Range |

## Aplicação Prática em Crypto

### Por que Wyckoff/SMC funciona bem em crypto?
1. **Mercado 24/7** com menos regulação = whales operam mais livremente
2. **Alavancagem alta** cria pools de liquidez (stops) gigantes
3. **Exchanges publicam dados de liquidações** — confirma sweeps
4. **Menos partícipantes sofisticados** = padrões mais puros que em forex/equities

### Ferramentas para Identificar
- **Bookmap**: visualiza liquidez em tempo real no orderbook
- **Coinglass**: mapa de liquidações (heatmap de stops)
- **TradingView**: desenhar OBs e FVGs manualmente
- **Volumetric Candles**: mostra volume comprador vs vendedor por candle

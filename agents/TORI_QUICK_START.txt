================================================================================
UNDERSTANDING THE OUTPUT
================================================================================

Each Setup Contains:

  market          — Pair name (BTCUSDT, ETHUSDT, etc.)
  timeframe       — Analysis timeframe (1W, 1D, 4H, 1H, 15m, 5m)
  trend_type      — LONG (ascending support) or SHORT (descending resistance)
  trendline_quality — A+ (excellent) or A (good)

  action_line     — Entry trigger level (trendline intercept)
  safety_line     — Stop loss level (action_line ±2%)
  current_price   — Current market price
  entry_price     — Price at proximity zone
  target_price    — Take-profit target (Fibonacci 1:5 extension)

  risk_usdt       — Entry - Stop (notional risk)
  reward_usdt     — Target - Entry (notional reward)
  ratio           — Reward / Risk (e.g., 5.17 = 1:5.17 R:R)

  confluence_score — Quality 0-100 (higher = better)
    • Volume climax +15 points
    • RSI extreme +15 points
    • Reversal confirmed +15 points
    • Baseline: 50 points

  trendline quality — Based on touches & slope validation
    • A+ = ≥3 touches, perfect slope
    • A = 2 touches, valid slope

  scalp_eligible   — True if R:R ≥ 10 (extreme risk:reward)

  rsi              — 14-period RSI (0-100)
  volume_signal    — +2=climax, +1=high, 0=normal, -1=drying
  touches          — Number of trendline touches detected
  slope_deg        — Trendline angle in degrees (5-35°)

================================================================================
KEY FILTERS FOR TRADER REVIEW
================================================================================

High-Quality A+ Only:
  $results | Where-Object { $_.trendline_quality -eq "A+" }

Entry Confirmed (reversal pattern detected):
  $results | Where-Object { $_.entry_confirmation -eq "CONFIRMED" }

Strong Risk:Reward (5:1 or better):
  $results | Where-Object { $_.ratio -ge 5.0 }

High Confluence (80+ score):
  $results | Where-Object { $_.confluence_score -ge 80 }

Scalp Opportunities (10x+ potential):
  $results | Where-Object { $_.scalp_eligible }

Combine filters:
  $best = $results | Where-Object {
    $_.trendline_quality -eq "A+" -and
    $_.confluence_score -ge 75 -and
    $_.ratio -ge 4.0 -and
    $_.entry_confirmation -eq "CONFIRMED"
  }

  $best | Format-Table market, timeframe, trend_type, ratio, confluence_score

================================================================================
INTERPRETING RATIO VALUES
================================================================================

R:R = Risk:Reward (Reward ÷ Risk)

  1.0 = 1:1   — Even bet (avoid)
  3.0 = 1:3   — Minimum for profitability (if win_rate > 25%)
  5.0 = 1:5   — Excellent (validated standard)
  10.0 = 1:10 — Exceptional (scalp eligible)
  15.0 = 1:15 — Extreme outlier (verify carefully)

Win rate break-even:
  • 1:1 ratio needs 50% win rate
  • 1:3 ratio needs 25% win rate
  • 1:5 ratio needs 17% win rate
  • 1:10 ratio needs 9% win rate

================================================================================
COMMON ISSUES & FIXES
================================================================================

Issue: "API error 40 / Credentials not found"
  → Set env vars or create config.local.ps1
  → See TORI_TRADES_SCANNER_README.md section "API Connectivity"

Issue: No setups found
  → Market may be in consolidation or data is incomplete
  → Try -MaxPairs 200 to analyze more pairs
  → Check -Verbose for specific pair failures

Issue: HTML page is slow/won't load
  → Too many rows in table (>2000)
  → Filter before rendering: $filtered = $results | Where-Object { $_.confluence_score -ge 70 }
  → Then render filtered set

Issue: Different results on subsequent runs
  → Normal (market price and indicators change constantly)
  → Rerun analysis to capture current state

5 CONFLUENCE SIGNALS
─────────────────────────────────────────────────────────────────────────────────

┌─ SIGNAL 1: VOLUME CLIMAX ───────────────────────────────────────────────────┐
│ Function:  Get-VolumeClimax -Volumes $volumes -Threshold 2.0               │
│ Trigger:   Current volume > 2.0x average volume                            │
│ Points:    20/100                                                          │
│ Logic:     Confirms climactic volume at trendline test (energy burst)      │
└────────────────────────────────────────────────────────────────────────────┘

┌─ SIGNAL 2: RSI EXTREME ─────────────────────────────────────────────────────┐
│ Function:  Get-RSIExtreme -RSI $rsi -SetupType "LONG"|"SHORT"              │
│ Trigger:   LONG: RSI < 30 (oversold)  |  SHORT: RSI > 70 (overbought)     │
│ Points:    20/100                                                          │
│ Logic:     Momentum extreme validates reversal setup                       │
└────────────────────────────────────────────────────────────────────────────┘

┌─ SIGNAL 3: FRACTAL PATTERN ────────────────────────────────────────────────┐
│ Function:  Get-FractalPattern -Opens $o -Highs $h -Lows $l -Closes $c     │
│ Trigger:   Bullish: Low w/ higher lows on both sides                      │
│            Bearish: High w/ lower highs on both sides                     │
│ Points:    15/100                                                          │
│ Logic:     Structural reversal at swing point                             │
└────────────────────────────────────────────────────────────────────────────┘

┌─ SIGNAL 4: CHoCH (CHANGE OF CHARACTER) ────────────────────────────────────┐
│ Function:  Get-StructuralBreak -Lows $lows -Highs $highs -SetupType ...   │
│ Trigger:   LONG: New swing low < prior support (break lower)              │
│            SHORT: New swing high > prior resistance (break higher)        │
│ Points:    15/100                                                          │
│ Logic:     Confirms macro trend structure break (force shift)             │
└────────────────────────────────────────────────────────────────────────────┘

┌─ SIGNAL 5: VOLUME PROFILE ─────────────────────────────────────────────────┐
│ Function:  Get-VolumeProfile -Candles $candles -Bins 20                   │
│ Trigger:   Price within 10% of peak volume price level                   │
│ Points:    10/100                                                          │
│ Logic:     Support/resistance cluster validated by volume concentration   │
└────────────────────────────────────────────────────────────────────────────┘

BONUS: Trendline touches = +5 points each (max +10 bonus for 4+ touches)


MAIN FUNCTION: Get-ConfluenceScoreEnhanced
─────────────────────────────────────────────────────────────────────────────────

SIGNATURE:
  Get-ConfluenceScoreEnhanced -Candles $candles -SetupType "LONG"|"SHORT" `
    -TrendlineStartPrice 95000 -TrendlineTouches 3

RETURNS:
  @{
    total_score            = 0-100           # Final confluence score
    breakdown              = @{...}          # Points per signal
    signals_fired          = @(...)          # Signal names fired
    rsi                    = 0-100
    volume_climax_ratio    = double
    peak_volume_level      = double
    trendline_touches      = int
  }

EXAMPLE:
  $score = Get-ConfluenceScoreEnhanced -Candles $candles -SetupType "LONG" `
    -TrendlineStartPrice 100 -TrendlineTouches 2

  if ($score.total_score -ge 75) {
    "GO: Confluence score = $($score.total_score)"
    $score.signals_fired | ForEach-Object { "  - $_" }
  }

CONFLUENCE SCORING FORMULA
─────────────────────────────────────────────────────────────────────────────────

score = 50 (baseline)

IF volume_climax:
  score += 20

IF rsi_extreme:
  score += 20

IF fractal_detected:
  score += 15

IF choch_detected:
  score += 15

IF volume_profile_match:
  score += 10

IF trendline_touches >= 3:
  score += MIN(10, (touches - 2) * 5)

FINAL: score = CLAMP(score, 0, 100)

KEY CONCEPTS
─────────────────────────────────────────────────────────────────────────────────

Walk-Forward Backtest
  Simulates real trading by walking through candles chronologically.
  Each candle represents time passing; mimics live trading decisions.

Confluence
  Multiple signals aligned = higher confidence setup.
  Solo signals = noise; multiple signals = valid trade.

Action Line
  Trendline price level where reversal expected.
  Price tests this level = opportunity to enter.

Risk:Reward Ratio
  Entry to stop vs. Entry to target.
  1:5 means risk $1 to make $5 (must be enforced).

Drawdown
  Maximum peak-to-trough decline in equity curve.
  Measures volatility and system stress periods.

Expectancy
  Average P&L per trade over sample.
  Positive expectancy = edge exists.

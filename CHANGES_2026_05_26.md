### 2. **New Library: LLM Quota Optimizer**

#### Arquivo: `agents/lib_llm_quota_optimizer.ps1` (nova)

**Funções**:
- `Invoke-DroneLimited()` — Wrapper com rate limiting intercalado
- `Test-SmaFlatline()` — Detecta SMA plano (<2% diferença)
- `Test-MesaSkip()` — Decide se pular Mesa (criteria-based)
- `New-QuotaTracker()` — Rastreia consumo daily
- `Update-QuotaTracker()` — Incrementa e alerta 80%

**Uso**:
```powershell
# Exemplo: Skip Mesa se SMA flatline
if (Test-MesaSkip -Candidate $candidate -CheckQuota $true) {
    # Pula direto para Mentor (economiza 3 drones)
}

# Exemplo: Rate limiting
$result = Invoke-DroneLimited -DroneFunc "Invoke-ThermalDrone" `
    -DroneParams @{Market=$market; Price=$price} `
    -RateLimitMs 2000
```

**Impacto de Quota**:
- Mesa skip flatline: ~40% skip = -40% Mesa calls
- Rate limit 2s: -30% parallelization waste
- **Total**: ~2.4K calls/dia (vs 1.4K+ antes)
